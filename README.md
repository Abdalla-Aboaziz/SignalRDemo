# SignalR Real-Time Chat

Real-time chat app built with ASP.NET Core SignalR — supports public messaging, group conversations, and message persistence using EF Core & SQL Server.

## Features

- 💬 Public chat — instant messaging across all connected users
- 👥 Group chat — join named groups and chat privately within them
- 💾 Message persistence — messages saved to SQL Server via EF Core

## Tech Stack

- ASP.NET Core MVC
- SignalR
- Entity Framework Core
- SQL Server
- JavaScript (SignalR JS Client)
- Bootstrap
